# Sorting Algorithms in C++

This repository contains implementations of major sorting algorithms in a single C++ file. The purpose of this project is to provide a clear and simple reference for learning, practicing, or demonstrating how different sorting algorithms work.

## 📌 Current Implemented Algorithms

- ✅ Selection Sort
- ✅ Bubble Sort
- ✅ Insertion Sort
- ✅ Merge Sort
- ✅ Quick Sort
- ✅ Bubble Sort (Recursive)
- ✅ Insertion Sort (Recursive)

More algorithms (like Insertion Sort, Merge Sort, Quick Sort, Heap Sort, etc.) will be added soon.

## 🧠 How It Works

Each sorting algorithm is implemented as a separate function that takes a `vector<int>` by reference and sorts it in ascending order. The sorted array is printed after each algorithm runs.
